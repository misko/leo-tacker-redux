# V5 canary: radio 192.168.1.15

Date: 2026-08-13  
Transport: standard libiio IP/TCP  
RF fixture: TX2 split by an SMA tee to RX1 and RX2; no LNB

## Safety and scope

The canary did not flash firmware, change QSPI, or alter boot configuration.
Before every receive or DDS operation, TX1 and TX2 attenuation were explicitly
set to `-80 dB` and read back. DDS channels were disabled after each injection.
The final state was TX1/TX2 at `-80 dB` with DDS disabled. SSH authentication
was unavailable, so `/opt/VERSIONS` was not collected. No other discovered
radio was contacted.

## Results

| Gate | Result | Evidence |
|---|---|---|
| Ordinary paired CI16 | Pass | Four equal `int16` arrays in I0,Q0,I1,Q1 order; 262,144 samples each |
| V3 metadata acquisition | Pass | Stable stream ID; buffer/sample sequences; gain/RSSI endpoints; 7–8 gain observations per frame |
| IQ/metadata association | Pass | Each metadata record described the exact 2,097,152-byte paired IQ refill |
| Timestamp mapping | Pass with measured uncertainty | Approximately 0.56–0.62 ms uncertainty; adjacent fits may overlap within uncertainty |
| Redux normalization | Pass | Live SPF records and complex samples translated to immutable Redux metadata and exact CI16 components |
| Fail-closed continuity | Pass | Redux rejected the live series at the first buffer sequence gap |
| TX2 tee loopback | Pass | Same 99.983 kHz tone on RX1/RX2; about 59/54 dB spectral contrast |
| DDS first-arm behavior | Confirmed | Weak attempts after retune were silent; a second arm produced the expected tone |
| Persistent changes | None | No flash, QSPI, boot, or service mutation |

At TX2 hardware gain `-20 dB`, DDS scale `0.05`, and RX gains `10 dB`, the
tone remained below five ADC counts peak. RX2/RX1 tone amplitude was about
0.58 and relative phase was approximately `-166.1 degrees`. These are fixture
observations, not calibration constants.

## IP continuity measurements

All measurements used paired CI16, 262,144 samples per refill, four kernel
buffers, parsed V3 metadata, and explicit sample-sequence accounting.

| Configured rate | Returned frames | Missing source frames | Gapped transitions |
|---:|---:|---:|---:|
| 2.083332 MS/s | 30 | 13 | 13 of 29 |
| 2.5 MS/s | 20 | 13 | 13 of 19 |
| 3.0 MS/s | 20 | 18 | 17 of 19 |
| 5.0 MS/s | 20 | 43 | 18 of 19 |

At the minimum rate, 30 returned refills represented 3.775 seconds of IQ but
required 6.301 seconds of wall time. Effective payload throughput was about
10 MB/s versus 16.67 MB/s required for continuous paired CI16. The host NIC
was negotiated at 2.5 Gb/s, so the bottleneck is downstream of that host link.
No overflow flag was asserted; the buffer and sample sequences were the only
reliable evidence of loss.

## Decision

The radio is accepted as a V5 functional canary. Ordinary paired IQ, metadata,
gain/RSSI reporting, timing, loopback, and Redux translation work as designed.

The current IP path is **not accepted for recordings represented as contiguous
IQ at any tested rate**. Redux must continue to fail closed on those claims.
Production qualification requires either a faster transport/topology, a USB
connection visible to the capture host, or an explicit discontinuous-recording
contract whose analysis windows never cross a source-time gap.
